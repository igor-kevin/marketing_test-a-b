Colunas:
 - user_id - identificador unico de usuário
 - test_group - "ad" viu o anuncio, "psa" (public service announcement) 
 - converted - booleano, True se comprou o produto, False se não
 - total_ads - quantidade de anuncios visto pelo usuário
 - most_ads_day - qual dia da semana o usuário viu mais anuncios
 - most_ads_hour - qual horário do dia o usuário teve mais anuncios apresentados
